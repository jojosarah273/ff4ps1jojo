FF4 Ultima 4bpp (16 color) portraits
------------------------------------
hacked in by Gedankenschild
new image assets by epigonone, tsushiy, Nicoc1991, uraba, xJ4cks 

In 2025 Gedankenschild pioneered a way to use 16 colors in the 
portraits in FF4 Ultima. This hack requires extra space in the rom, 
so the images were moved and new palettes were carved out.
Because of this, all the heroes' faces get upgraded to 4bpp graphics.
ALSO, these changes are completely incompatible with classic, 8 color 
(3bpp) portraits, because the location in the game's rom is new.

The original set was the Mobile portraits, sourced from the Android 
& iOS release of FF4. Sprite hackers and artists in the the FF4 Ultima 
Discord added more options, and created 2 more sets, based on the Pixel 
Remaster version and on the Brave Exvius game's sprites.

If you want to use the custom portraits, please use one of the main sets 
first, then patch on any single portraits after that.
