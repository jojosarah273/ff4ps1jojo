CHANGES: The amount of colors used in each enemy sprite. This doubles them to 16!
(They become 4bpp images, not 3bpp as seen in the original version of the game.)

EFFECT: Ports over enemy sprites from FFIV Wonderswan Color version, 
which have much more colors in each sprite for better depth of shading.

- Enemy Graphics 4bpp Upgrade.ips
This patch adapts the updated sprites to the larger designs seen in the original SNES game!
This one must be used if you wish to use MObreck's FFAtB addenda for this project.

- Enemy Graphics 4bpp Upgrade (GBA-size).ips
This patch makes the large-size enemies a bit smaller, like in "FFIV Advance"
(They were shrunk down for the smaller screen.) 


NOTE: Use these BEFORE the experimental 4bbp battle bgs patch!
You will see some bugged sprites if you use these after that one.

>>>>>>   Either one of these IS REQUIRED if you wish to use that patch! <<<<<<
